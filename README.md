# Jessica Zheng — Portfolio

Single-page trilingual portfolio (Indonesian, English, Chinese), built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design and animations
- `script.js` — language switcher, mobile navigation, scroll reveal, back-to-top

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with your email address.
2. Replace `YOUR_LINKEDIN` with your LinkedIn profile slug or URL.
3. Review the Mandarin training entry and confirm its exact certificate title/provider if you want it displayed more specifically.
4. Add real project screenshots when available; the current project panels are CSS-generated visual placeholders.
5. Verify every date and project description against your final CV.

## Publish with GitHub Pages
Upload the four files to the root of your repository, then open **Settings → Pages** and choose **Deploy from a branch → main → /(root)**.

The page uses Google Fonts from the web. A connection is required to load those fonts; fallback fonts are included.
